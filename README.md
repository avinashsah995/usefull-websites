# Useful Websites Collection 🌟

A curated collection of powerful, free-to-use web tools and resources for designers, developers, and creative professionals. This application showcases essential websites that can boost productivity and enhance creativity.

![Project Preview](public/vite.svg)

## ✨ Features

- **Curated Collection**: Carefully selected tools for design, productivity, and development.
- **Modern UI/UX**: Premium dark theme with glassmorphism effects and smooth animations.
- **Responsive Design**: Fully responsive layout that looks great on all devices.
- **Detailed Insights**: In-depth descriptions and feature lists for each recommended tool.
- **Categorization**: Easy-to-navigate categories for different types of tools.

## 🛠️ Tech Stack

- **Frontend Framework**: [React](https://react.dev/) with [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: Vanilla CSS with CSS Variables for theming
- **Routing**: [React Router](https://reactrouter.com/)
- **Icons**: SVG Icons

## 🚀 Getting Started

Follow these steps to get the project running locally on your machine.

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/avinashsah995/usefull-websites.git
   cd usefull-websites
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:5173` to view the application.
